# Sitrep sources companion

Private draft companion for `/workspace/wf-sitrep/`. Not a production file.
Snapshot: **15 November 2026, 17:00 America/New_York (2200Z)**.

Rules used: no invented coordinates, dates, or status; no marker without a named place; CONFIRMED only with two independent named sources (or matching official statements from opposing sides plus press); REPORTED for one reputable outlet or a single official statement; CLAIM for a single unverified military claim; DELTA when control claims conflict; every event has a source class and at least one URL or named outlet.

Overview map center was shifted to latitude 18, longitude 15, zoom 2 so Americas, Africa, and Asia-Pacific markers can appear. Existing theater map centers were otherwise left in place. `THEATER_ORDER` was not changed. Iraq items are filed under **Iran / Gulf** (closest existing theater) and also on Overview.

Global Database of Events, Language, and Tone filter changes and a 24-hour / 3-day / 7-day / 30-day time toggle are **not** in this draft; they are reserved for a separate pull request.

## Live overlay note (Iraq gap; filter not changed)

`scripts/fetch_live.py` AOR tokens already include "iraq". Country-level-only rows are still dropped: `coords_match_place()` returns false if the first toponym is in GENERIC (which includes "iraq") or if coordinates round to Iraq's country centroid (33.0, 44.0). `src/live.ts` `saneLive()` applies a similar GENERIC drop. Place-level rows such as "Baghdad, Iraq" would not be dropped by GENERIC alone. Much of Iraq also sits west of the Iran bounding box (west edge 47.8E) and north of the energy box, so `theater_for()` would tag those rows "overview", and the Overview live panel hides events already tagged theater "overview". Today's `live.json` (generated 2026-11-15T17:50:31Z) had 7 events and none in Iraq.
